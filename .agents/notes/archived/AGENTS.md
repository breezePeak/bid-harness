# AGENTS.md — 归档 Agent Notes

归档目录中的 Markdown 正文是冻结的历史记录，不作为当前规则依据。不得编辑、格式化、翻译、删除或移动已封存正文；新决策写入活跃 Agent Note 或当前文档。

归档时只移动正文并添加归档日期，随后修复或删除入站链接。现存英文正文可以与中文正文一起归档，不要求语言配对或一致性记录。不得检查或修复归档正文中的出站链接。

运行 [dsh-archive-agent-notes](../../skills/dsh-archive-agent-notes/SKILL.md) 流程，并用 `pnpm run verify-archived-agent-notes --write` 封存新正文。普通校验拒绝已封存正文的更改、缺失、未知类别和无效归档头部。
