# Agent Note: Word 模板证据解析与冲突确认

Status: implemented

## Problem

Word 格式页把样式角色和最终格式混在同一次选择中。已识别为标题或正文的 Named Style 会遮蔽段落与 Run 直接格式，Theme 标识可能被当成字体名称；模板正文中的格式说明不会自动参与合并。页面同时暴露页面参数、候选映射、自然语言描述和内部解析数据，用户需要理解实现细节才能导出。

## Decision

DOCX 解析先读取 docDefaults、Theme 字体方案、`basedOn` 继承、Named Style、段落 `pPr`、Run `rPr`、页面和编号。角色判断独立使用样式名、`outlineLvl`、文档结构及模型候选映射；同一候选通过 `roles` 与 `samples` 表达多个用途和样本，标准 `Caption`、`题注`、图题及表题样式支持图题与表题共享。`DOCX_TEMPLATE_PARSER_VERSION` 为 4，缓存文件名携带版本。

当前会话模型在模板上传内只接收程序提取的正文段落、字段和候选，输出带模板原文证据的格式规则及候选 ID 映射。OOXML 提取、模型解释、浏览器确认和磁盘配置共用 `normalizeFormatValues()`：程序先把数字字符串、磅或 pt 字号、常用中文字号、倍数行距及字符或毫米缩进转换为内部数值和单位枚举，再执行严格字段 Schema、原文包含关系与候选 ID 校验；完整请求记录为 `bid.word-format.request`，不进入正文对话。确定性解析成功后立即保存，解释失败只向本次响应附加可重试提示。

磁盘格式状态版本 2 分别保存 `extracted`、`modelInterpreted`、`conflicts`、`resolved` 和 `userConfirmed`；每份模板拥有独立状态文件，身份及选择由[项目模板库](2026-09-12-bid-word-template-library-and-rendered-pages.md)管理。模型没有给角色映射时，同角色 Named Style 与直接格式候选全部参与冲突；模型给出候选 ID 后只采用该候选，不再混入同角色的其他直接格式。每个候选只以 Word 级联后的有效值参与合并，继承链中已被覆盖的值仍保留在提取证据中，但不制造格式冲突。证据依次按系统默认、docDefaults/Theme、Named Style、直接格式、模板正文说明、用户要求和用户确认提高优先级；相异的候选、语义规则或用户确认不会静默覆盖，而是保留全部证据和暂定 `resolvedValue`。用户只能在冲突证据值中确认，确认后更新 `userConfirmed`、冲突状态和 `resolved`，不改写提取或模型解释。

Word 格式页只显示模板上传区、一级标题、二级标题、正文、图题和表题的主要格式表，以及固定短内容的效果预览；常用中文字号同时显示原名称与对应磅值。上传开始后清除可见识别结果，确定性解析成功即发布新模板，模型解释失败显示可重试提示。冲突单元格标红并打开单字段选择框；底部唯一“导出 Word”按钮在存在未确认冲突时提示数量并定位首项，确认完成后生成并下载。浏览器 HTML、页数估算与 DOCX 生成只读取同一份 `resolved`。图题和表题拥有独立前缀、数字格式及两个分隔符，导出时写入两个 Word 原生编号列表。

表格前后已有题注时保留名称并使用生效格式编号；两表之间的题注归属后表。无题注表格在表前使用表头文字连接为名称，与已有题注共用表题计数器，表前题注和表格首行保持同页。识别兼容“表1”“表 1”及生效前缀，源章节不因导出而改写。

## Alternatives considered

**继续让用户编辑全部格式字段和候选映射。** 不采用；确定性 OOXML 信息应由程序合并，用户只需处理证据无法消除的歧义，完整编辑器会重复暴露内部模型并让预览草稿偏离导出状态。

**把模板文本和 XML 全部交给模型重建格式。** 不采用；模型不拥有 Theme、继承、单位换算和编号等确定性事实，且无法保证候选引用与字段合法性。

**按 Word 级联顺序静默接受最高优先级。** 不采用；直接格式与样式或正文说明的差异可能是示例偏差，也可能是模板意图，静默覆盖会把真实歧义伪装成正常结果。

**保留正文中的“图1”“表1”普通文字。** 不采用；序号在 Word 中无法随插入、删除自动更新，图题和表题也无法独立计数。

**导出时调用模型为表格命名。** 不采用；生成文件不应改写已审核正文或引入新的模型调用。缺少题注时使用表头已有文字，专用名称由用户在正文中明确给出。

## Consequences

任意合理 DOCX 通过同一解析路径产生可审计证据，Named Style 不再吞掉实际段落格式，Theme ID 不进入最终字体，最终字号、行距和缩进使用数值。用户界面不提供任意底层 JSON 或全字段编辑；未被模板、模型或证据确认的值继续使用系统默认。模板正文最多保存前 2000 个非空段落，每段最多 1000 字符；超出范围会留下解析提示。磁盘状态版本保持 2，已有数值配置不迁移；配置版本 1 仍需重新上传模板。

[S5 常驻审核与按需导出](2026-09-04-bid-s5-persistent-review-export.md)继续拥有导出准入和项目生命周期；[模板二进制上传](../bug-fix/2026-09-08-bid-docx-template-binary-upload.md)继续拥有请求体、大小限制与来源校验。本记录只拥有模板证据、冲突状态、预览与最终格式一致性；两份既有记录仅被部分扩展，保留为当前约束，不归档。
