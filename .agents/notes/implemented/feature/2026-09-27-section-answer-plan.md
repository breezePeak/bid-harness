# Agent Note: 章节任务级依据计划

Status: implemented

## Problem

资料映射记录材料用途和写作维度，却不能说明每项必答任务将如何回应、依据支持到哪里以及哪些现实事实仍缺输入。旧映射和目录变更后的空索引也容易被误认为已经具备成文依据。

## Decision

章节研究、Writer 和 Reviewer 使用同一规范任务清单。Child 用运行内 R 引用目标、已读材料引用提交逐项回应；Host 绑定 S2 记录、章节职责、本地分块和 Web Chunk 的身份。正式 `answer_plan` 保存在章节 Evidence Mapping 中，缺失表示尚未完成本次依据准备。每个目标至少有一项回应，允许同一目标同时有已支持内容、拟采用方案和真实缺口。程序核对目标、来源与字段，语义复核判断内容是否具体、来源是否真正支持结论。

材料记录与计划相互约束：删除或更换材料后，依赖该材料的计划不能保留为有效的 supported 结论。结构和章节职责变化使计划重新进入复核；新叶节不能继承父章的完成结论。真实缺口保留为合法研究结果，而非 Schema 故障。

## Alternatives considered

**仅增加 `ready` 状态。** 单个布尔值无法表达某项任务可写而另一项仍缺现实事实，也无法追溯正文的依据边界。

**根据材料条数或关键词自动判定质量。** 材料存在不证明相关性，零本地资料也不排除有理由的方案设计。

## Consequences

历史映射继续可读，但受影响章节在写作前必须完成定向依据准备。研究输出增加逐项计划，终审需核对具体回应、引用和事实边界；模型仍可能作出错误的语义判断，因此真实模型样例需单独验收。
