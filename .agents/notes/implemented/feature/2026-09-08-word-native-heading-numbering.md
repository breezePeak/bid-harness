# Agent Note: Word 原生多级标题编号

Status: implemented

## Problem

标题序号作为普通文字写入 DOCX 时，编辑器无法在插入、删除或移动章节后重新计数。标题虽有级别，编号却与可编辑的目录结构脱离。

## Decision

导出使用 Word 原生多级列表，六级定义分别关联 `Heading1` 至 `Heading6`，样式显式声明大纲级别。源标题开头的十进制序号级数与标题深度一致时，段落引用编号实例，生成器移除该序号并保留其余富文本；正文小标题保留原文并显式取消编号，不从样式继承列表。文档标题不参与编号，正文列表不加入标题列表。用户可在 Word 中通过标题插入和更新目录。

十进制模式以确认目录编号为准。部分导出跳过未完成章节时，在编号缺口建立以各级目录序号起始的列表，连续章节共用该实例；返回该实例尚未出现的祖先级别时建立新的起始定义，避免 Word 把祖先当作该列表的首个标题。预览计数器同步更新目录序号。模板模式按模板规则计数，无编号模式隐藏目录序号。

编号定义与浏览器预览计数器读取同一配置，支持十进制、模板和无编号模式。模板模式保留各级数字形式、编号结构和起始值；不随父级重启的级别通过 `w:lvlRestart=0` 连续计数。当前 docx 级别 API 未暴露该属性，打包后只在关联标题样式的级别补齐它，其他文档部件保持原样。

本决策替代 [S5 按需导出](2026-09-04-bid-s5-persistent-review-export.md) 中编号仅作为显示文字的限制，其项目锁、配置持久化及按需导出职责保持有效。

## Alternatives considered

**保留普通序号文字，只给标题设置大纲级别。** 可以让目录识别标题，却不能让编号随正文编辑自动变化。

**为每个章节创建独立编号实例。** 会割裂同级计数关系，章节移动或在 Word 中新增标题后无法自然续号。

**忽略模板的连续计数设置。** 输出会与配置和预览不一致，因此在生成的编号部件中补齐依赖尚未支持的属性。

## Consequences

程序提供起始序号和编号规则，最终编号与分页由编辑器负责。无编号模式仍保留标题样式供目录识别。基础正文样式和标题基准样式分别定义，避免正文字符缩进影响标题。定向测试检查连续章节共用实例、缺口起始值、返回祖先级别、正文标题原文及生成文件的回读；源码 Loader 快照固定应用导出链路产生的原生编号关联。部分导出的编号缺口拆分列表，Word 中跨缺口移动章节后需要按编辑意图重新连接列表。
