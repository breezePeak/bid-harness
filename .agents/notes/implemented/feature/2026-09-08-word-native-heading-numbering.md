# Agent Note: Word 原生多级标题编号

Status: implemented

## Problem

标题序号作为普通文字写入 DOCX 时，编辑器无法在插入、删除或移动章节后重新计数。标题虽有级别，编号却与可编辑的目录结构脱离。

## Decision

导出使用一个 Word 原生多级列表，六级定义分别关联 `Heading1` 至 `Heading6`，段落和标题样式共同引用同一编号实例，样式显式声明大纲级别。生成器移除源标题开头的序号，保留其余富文本；序号只由列表生成。文档标题不参与编号，正文列表不加入标题列表。用户可在 Word 中通过标题插入和更新目录。

编号定义与浏览器预览计数器读取同一配置，支持十进制、模板和无编号模式。模板模式保留各级数字形式、编号结构和起始值；不随父级重启的级别通过 `w:lvlRestart=0` 连续计数。当前 docx 级别 API 未暴露该属性，打包后只在关联标题样式的级别补齐它，其他文档部件保持原样。

本决策替代 [S5 按需导出](2026-09-04-bid-s5-persistent-review-export.md) 中编号仅作为显示文字的限制，其项目锁、配置持久化及按需导出职责保持有效。

## Alternatives considered

**保留普通序号文字，只给标题设置大纲级别。** 可以让目录识别标题，却不能让编号随正文编辑自动变化。

**为每个章节创建独立编号实例。** 会割裂同级计数关系，章节移动或在 Word 中新增标题后无法自然续号。

**忽略模板的连续计数设置。** 输出会与配置和预览不一致，因此在生成的编号部件中补齐依赖尚未支持的属性。

## Consequences

程序不计算 Word 最终显示的序号或目录页码，编号与分页由编辑器负责。无编号模式仍保留标题样式供目录识别。基础正文样式和标题基准样式分别定义，避免正文字符缩进影响标题。定向测试检查共享实例、六级样式关联、无手写序号、模板连续计数及生成文件的回读；源码 Loader 快照固定应用导出链路产生的原生编号关联。
