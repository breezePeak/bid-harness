# Agent Note: S4 目录复核输出预算与后续恢复

Status: implemented

## Problem

思考模型在输出完整质量报告前会消耗输出 token，目录轻量复核的固定 2,048 token 上限会终止合法请求。原 S4 的旧输入预算阻断解除后，新复核失败仍被同一 Work 的历史 blocked 拒绝，尽管 Host 已接纳恢复且有限次数尚未耗尽。

## Decision

目录复核使用所选 Agent 的输出配置，缺省时采用模型元数据，两者未知才使用保守默认值。输入容量扣除同一实际输出预算，避免审核请求与分片程序使用不同容量。输出耗尽具有独立错误码，立即保留失败，不通过相同上限的报告修复轮次消耗重复请求。

旧固定输入预算 blocked 的例外要求原 S4、精确历史诊断和已接纳的恢复请求；后续不同 Run 的可修失败按原 Work 剩余次数继续。当前失败为权限、输入、凭证或服务商真实容量阻断时仍拒绝；原预算耗尽不授予恢复。驱动依据当前 Host 资格派发，不因已失效的历史 blocked 重复终止通知。

输出超限恢复与旧预算恢复共用严格候选核验：检查点和待审目录缺失或身份不匹配时失败，有效研究保留，审核及最终检查仍必须完成。恢复请求和轮次保留在原会话，不修改历史结算或重置预算。

完整复核允许采购原文补足 S2 摘要遗漏。真实来源支持且已由当前叶节承接的任务，不因 S2 未单列条目被判覆盖缺失或要求补造身份；实际关联错误、职责冲突与未承接任务仍阻断。分片索引由程序标明局部视图，未显示的章节不能被推断为全书缺失，完整覆盖仍由全部分片及独立关系复核汇总。

本记录补充[硬预算分段与旧任务恢复](2026-10-09-s4-review-partitions-and-legacy-recovery.md)的后续失败链路；该记录仍拥有无损输入分段与历史诊断例外。[恢复结算](2026-10-06-bid-recovery-settlement.md)仍拥有有限派发和终止通知，[当前独立复核](2026-10-10-s4-research-facts-and-independent-review.md)仍拥有研究事实及 Final Check 失效规则，均保留活跃。

## Alternatives considered

**仅增加固定输出上限。** 部署可选择不同模型及思考模式，另一固定值仍会覆盖用户配置，并使输入预算与实际请求脱节。

**清空 blocked 历史或重置 Work。** 会丢失审计关系与已用次数，且无法证明原研究候选有效；例外必须绑定已接纳的同一 Work 恢复。

## Consequences

较大输出预算可能缩小输入分片并增加调用成本；达到模型真实容量时仍明确失败。真实 Host 和无密钥会话回放覆盖旧 blocked、复核输出超限、再次重启、剩余预算、候选保留及正式确认；这些验证不代替用户项目的真实模型审核。
