# Agent Note: S4 完成验收与 Word 导出重置

Status: implemented

## Problem

S4 子工具的局部完成和 Web 工具故障不等于 Host 已验收任务完成。Word 格式状态只保存每份模板最近一次导出，阶段重置无法在自定义输出目录中识别更早的项目生成物。

## Decision

`completeMappingSubmission` 只保存候选和复核进度，`runTaskAttempt` 在收集本轮工具结果、分类 Web 故障并通过范围与完整性校验后提交完成检查点。完成日志与检查点冲突时恢复为待验收状态。

同一 Run 的临时 Web 故障共享重试额度和退避时段；额度耗尽后保存首个 Provider 根因并中止整批调度。

每次 Word 导出在同一发布事务登记实际生成的 DOCX、Markdown 快照和流程图。阶段重置清除显示引用和登记记录，并在自定义输出目录中仅删除登记的项目文件。

## Alternatives considered

**继续由 finish 工具提交完成。** 工具无法得知同一轮稍后的 Web 调用和 Host 范围校验结果，会把未验收候选写成完成事实。

**扫描或递归清空自定义输出目录。** 目录内可能有用户文件，路径位置不能证明其属于本项目导出。

**只为每份模板保存最后一次导出。** 该引用是下载入口，不是历史生成物清单，无法覆盖连续导出的所有附属文件。

## Consequences

失败后保留可恢复的草稿和复核记录，但恢复流程会重新验收而非跳过任务。未登记的历史文件不会被猜测删除；首次登记后的导出才具备完整、可证明的清理归属。
