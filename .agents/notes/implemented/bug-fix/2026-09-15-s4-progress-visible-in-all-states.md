# Agent Note: S4 进度在所有阶段状态保持可见

Status: implemented

## Problem

S4 目录生成/资料映射的进度卡片只在已成功读取任务日志且阶段状态属于特定执行状态时显示。等待启动、日志尚未生成、阶段暂停或复核失败时，用户看不到进度条，也无法区分“尚未建立任务”和“已有任务但执行失败”。

## Decision

BidStagePanel 只要处于 Main Session 的 S4 阶段就渲染进度卡片。进度读取不到时使用 0 个任务的占位数据并保留同步提示；读取成功后显示 Host 返回的完成、进行中、未开始和失败计数。阶段状态不再决定是否隐藏进度卡片，Subagent 和非 Bid Session 仍不显示项目进度。

## Alternatives considered

**只在 Host 返回非空进度时显示：** 保留了原有的状态缺口，等待启动和复核失败仍没有可见反馈，因此不满足 S4 进度始终可见的要求。

**为每种失败状态单独增加显示分支：** 状态枚举继续扩展就会重复产生遗漏；以 S4 阶段作为显示边界更直接，也保留了 Host 进度数据的权威性。

## Consequences

S4 刚进入或尚未生成日志时会显示 `0 / 0 (0%)`，并同时显示同步提示；这表示任务计数尚未可读，不表示任务已经完成。复核失败和暂停时仍保留最后一次成功读取的计数，并显示失败任务信息。进度读取和 Host 日志协议不变。
