# Agent Note: 产物校验失败由主 Agent 持续接管

Status: implemented

## Problem

执行器抛出的目录结构、响应点覆盖和局部操作错误属于可修复候选问题。仅用少量错误码识别可恢复失败，会把这些错误保存为 blocked，阻止主 Agent 获得恢复工具。目录候选与修复操作使用不同文件路径，按输出路径匹配还会遗漏主 Agent 的指令；已有修复回执也可能阻止新接管实际执行。

## Decision

Host 保留阶段执行和能力任务中的结构化问题，并检查全部问题中的输入冲突、正式清单不匹配、提供方与权限故障；这些故障优先阻止自动修改。普通未知异常不推断为内容问题。可修复产物继续交给绑定的主 Agent，不因相同问题指纹或两次接管而撤销权限，原生 Goal 的生命周期与总轮数仍决定是否继续。非模型故障按[模型修复挂起边界](2026-09-28-bid-model-only-failure-suspension.md)结束当前 Run。

S3 将针对目录的接管指令传入格式、字段和局部操作修复。Host 接受的当前 work 指令可授权一次新的确定性修复；普通中断恢复仍遵守既有回执限制。正式输入、响应点编号、局部编辑范围与最终校验保持原有权限，成功修复才发布新目录与回执。

本决策部分替代[主会话有界接管](../feature/2026-09-23-bid-s2-s5-goal-recovery.md)的内容失败次数限制，以及[S3 有界恢复](2026-09-21-s3-bounded-outline-generation-recovery.md)中已授权接管的回执限制；两份记录仍保留 Goal 绑定、运行身份、普通恢复和提交时序的依据。

## Alternatives considered

**只添加两个目录错误码。** 新的候选校验规则仍可能漏掉恢复分类，无法覆盖执行器与最终 Validator 对同类失败的不同表示。

**主 Agent 直接覆盖正式目录或忽略校验。** 会绕过 Run 提交权限及响应点覆盖检查；主 Agent 通过受控指令指导原执行器修复。

**重复问题立即停止。** 一次无效修复不代表主 Agent 无法改变处理办法，且失败操作可能没有发布候选，指纹相同不能证明已经尝试过全部可行方案。

## Consequences

内容错误可消耗更多模型轮次；实际问题、接管指令和次数仍留在会话事件中。瞬时操作重试及写作计划派发保留各自的限制，用户停止和正式确认仍阻止自动推进。单元测试覆盖混合问题分类、重复与多次接管、修复回执和指令传递；真实 Loader 回放覆盖目录失败后同一主会话调用诊断与恢复工具。
