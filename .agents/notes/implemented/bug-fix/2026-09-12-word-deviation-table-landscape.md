# Agent Note: 技术偏离表使用横向 Word 页面

Status: implemented

## Problem

技术偏离表通常包含技术条款、响应内容和偏离说明等宽列。它继承整份文档的页面方向时，纵向页面会压缩单元格，影响阅读和填写。

## Decision

DOCX 渲染器将标题名称为“技术偏离表”的内容及其后续子内容置于独立横向页面节；遇到同级或更高层级标题时建立新节并恢复用户选择的页面方向。各节复用同一页边距、页眉和页脚。浏览器预览继续只呈现内容样式，不模拟分节分页。

[已保存正文导出](2026-09-12-word-export-saved-content.md)继续决定技术偏离表是否进入导出；本记录只规定其进入 DOCX 后的页面方向。

## Alternatives considered

**将整份技术标设为横向。** 会改变普通正文的阅读版式，且不能满足仅宽表需要横向页面的场景。

**增加可配置的章节方向。** 当前只有技术偏离表需要固定横向，新增配置会增加无消费者的格式选择和持久化状态。

## Consequences

技术偏离表前后会发生分页，表格获得横向可用宽度，普通章节保留原页面方向。定向 DOCX XML 回归固定二级标题、相邻页面节的方向和纸张尺寸。
