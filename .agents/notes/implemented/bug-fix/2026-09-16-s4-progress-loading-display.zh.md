# Agent Note: S4 进度加载状态不显示为零

Status: implemented

## Problem

S4 进度卡片在第一次异步读取、投影校准或短暂同步失败期间没有有效任务快照，却把缺失数据渲染为 `0 / 0 (0%)`。用户会把加载占位误认为任务进度被清零，进度卡片也因此在占位值与真实值之间跳变。

## Decision

S4 进度卡片保留空进度条的布局，但在没有有效快照时显示“进度同步中…”和“同步中”标签，不显示任务数量、百分比或包含零值的无障碍摘要。读取到有效快照后才显示任务统计；同一工作身份的已有快照仍由现有轮询逻辑保留。

## Alternatives considered

**直接隐藏进度卡片。** 不采用。隐藏卡片会让同步期间的布局和阶段反馈消失，用户无法知道进度入口正在等待数据。

**继续显示 `0 / 0` 并仅依赖上方同步提示。** 不采用。卡片自身仍会传达错误的零进度，屏幕阅读器也会读出错误统计。

## Consequences

首次读取和暂时重同步期间，卡片只表达“尚未获得进度”，不会伪造真实的零任务状态。空进度条仍占据原有位置，拿到快照后直接切换为实际百分比；真实任务总量变化导致的百分比调整仍按任务日志反映。
