# Agent Note: Bid S5 审核结果投影

Status: implemented

## Problem

S5 目录可依据章节审核状态标出需关注项，但章节详情未展示已保存报告中的问题，且无正文的失败章节无法选中读取 Writer 或 Reviewer 的执行记录。

## Decision

工作台目录和章节详情从同一份确认目录、章节正文、审核报告与执行日志投影状态。审核报告仅在其候选正文哈希匹配当前章节时生效；章节审核详情直接显示已保存报告的风险结论、覆盖缺口、外部资料缺口、职责冲突、全局约束违反、未获支持的事实或承诺和未通过的质量检查。报告没有明确修改建议时不返回建议。执行日志标记章节失败时，详情以失败状态显示最后一个未接受 Writer 或 Reviewer 尝试中的真实问题或停止原因，并与正文质量问题使用不同来源标识。

文档级全局报告单独投影 document 问题和 delivery 待办，不进入章节目录状态或章节问题计数；报告结构、证据和责任归属由[全局合规审核](2026-09-09-bid-s5-global-compliance-review.md)约束。

可选中条件包含已有正文、正文需要修复和 Writer 或 Reviewer 执行失败。无正文时阅读区保留无正文提示，审核栏仍显示可用的失败详情。没有已保存审核报告时只显示等待或审核中；异常状态缺少详情时提供仅重新读取当前产物的入口，不触发模型或重新审核。刷新和轮询重新读取这些产物，当前章节仅显示这次读取结果。

这项详情投影补充 [S5 常驻审核与按需 Word 导出](../feature/2026-09-04-bid-s5-persistent-review-export.md)；S5 的 Subagent 写作、独立审核和 Host 调度仍由 [S6 章节写作由 Host 调度独立 Subagent](2026-09-01-s6-subagent-chapter-scheduling.md) 约束。

## Alternatives considered

**打开章节时重新调用 Reviewer。** 不采用；已保存的审核报告是用户可见结果的来源，读取页面不能改变 S5 任务、模型成本或报告内容。

**把执行失败包装成正文质量问题。** 不采用；执行记录中的角色、停止原因和校验问题说明的是 Writer 或 Reviewer 未完成，不能表述为正文缺陷。

**只在目录提示失败。** 不采用；目录无法承载问题详情，且会使没有正文的失败章节失去唯一的排查入口。

## Consequences

目录状态灯、顶部需关注计数和章节详情使用同一章节状态：缺少资质或证书等项目资料时显示黄色，正文需要修复时显示红色，编写或审核执行失败保持失败状态。所有审核问题按高、中、低风险显示，不使用审核结论阻断阶段或导出；文档级问题和交付待办位于独立区域，不污染章节计数。审核报告的新版本会在下一次刷新投影替换旧问题；没有报告或日志详情时客户端明确保留未知原因，而不是补造内容。具体边界由[审核风险不阻断](2026-09-12-bid-s5-advisory-review-risk.md)记录。

客户端测试覆盖真实问题展示、通过状态、无正文失败章节、异常空详情及章节切换后的自动刷新；Host 测试覆盖审核报告字段与执行日志失败原因的读取。
