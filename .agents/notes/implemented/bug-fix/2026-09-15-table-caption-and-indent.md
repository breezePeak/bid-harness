# Agent Note: 表题与正文表格首行缩进统一

Status: implemented

## Problem

无模板渲染器会从表格首行列名自动生成表题，可能重复正文表题并掩盖表头；表题校验、预览和导出对中文或英文标题开头的判断不一致，可能截断标题或漏掉合法表题。模板合成会误删表格前的普通段落，或在模板没有表题时丢掉 S5 表题。正文两字符首行缩进还可能从正文样式或原始模板单元格继承到表格内，导致表头和数据行向右空出两个字符。

## Decision

S5 Writer 要求每张 Markdown 表格在紧邻上方保存简洁准确的无编号表题，提交校验和完成校验拒绝缺失表题的章节，并复用现有章节修复流程。表题由共享解析器按独立单行的 `表 标题` 形式识别，只有带明确边界的旧编号前缀才会移除，因此解析、DOCX、HTML 和页数估算保留同一份完整标题。DOCX 和 HTML 只读取显式表题，由渲染顺序分配编号；第一行列名始终作为表头保留。

模板合成建立已完全消费的源表格与目标表格的关联。目标已有映射到表题角色的明确题注时保留目标题注并删除重复源题注；目标没有题注时，将源题注移动到目标表格紧邻上方，并只把它加入样式、编号和关系合并输入，不再插入正文锚点。普通说明段落不因表格消费而删除。

无模板表格单元格和模板合成后的正文表格统一显式写入 `w:firstLine="0"` 与 `w:firstLineChars="0"`，保留其余段落属性；HTML 预览和页数估算只把表格上方的显式表题识别为表题。

## Alternatives considered

**继续从表头推断缺失表题。** 会让导出阶段替模型做语义命名，无法区分真正表题和表头，也会产生重复题注。

**只修改默认表格样式。** 原始模板和已生成段落可能带有直接缩进，样式默认值不能覆盖这些属性。

**继续删除表格前一个段落。** 该位置也可能是正文说明，无法证明它应与被消费的模板表格去重。

**让源题注继续随正文插入。** 目标模板没有题注时会把题注留在正文插入位置，既与表格脱离，又可能造成重复或丢失；按源表格与目标表格的关联移动题注能同时保留归属和资源引用。

## Consequences

旧正文缺少表题时需要在 S5 对对应章节定向修复；纯首行缩进问题只需重新导出。无模板、模板合成、浏览器预览和页数估算对表题归属保持一致，模板之外的正文段落属性不受表格清理影响。
