# Agent Note: 表题与正文表格首行缩进统一

Status: implemented

## Problem

无模板渲染器会从表格首行列名自动生成表题，可能重复正文表题并掩盖表头；模板合成会误删表格前的普通段落。正文两字符首行缩进还可能从正文样式或原始模板单元格继承到表格内，导致表头和数据行向右空出两个字符。

## Decision

S5 Writer 要求每张 Markdown 表格在紧邻上方保存简洁准确的无编号表题，提交校验和完成校验拒绝缺失表题的章节，并复用现有章节修复流程。DOCX 和 HTML 只读取显式表题，由渲染顺序分配编号；第一行列名始终作为表头保留。模板合成只移除带有 `DshTableCaption` 样式且直接关联已消费表格的题注段落，不再按位置删除普通段落。

无模板表格单元格和模板合成后的正文表格统一显式写入 `w:firstLine="0"` 与 `w:firstLineChars="0"`，保留其余段落属性；HTML 预览和页数估算只把表格上方的显式表题识别为表题。

## Alternatives considered

**继续从表头推断缺失表题。** 会让导出阶段替模型做语义命名，无法区分真正表题和表头，也会产生重复题注。

**只修改默认表格样式。** 原始模板和已生成段落可能带有直接缩进，样式默认值不能覆盖这些属性。

**继续删除表格前一个段落。** 该位置也可能是正文说明，无法证明它应与被消费的模板表格去重。

## Consequences

旧正文缺少表题时需要在 S5 对对应章节定向修复；纯首行缩进问题只需重新导出。无模板、模板合成、浏览器预览和页数估算对表题归属保持一致，模板之外的正文段落属性不受表格清理影响。
