# Agent Note: Bid 主 Agent 按能力范围重规划未完成任务

Status: implemented

## Problem

目录结构修改被交给只能深化章节子树的能力时，局部任务无法调整顶层关系。复核只看覆盖和编写要求会把未实现的结构目标当成完成；失败后要求用户再次授权也会中断原任务。

## Decision

能力契约说明实际修改范围，Main Agent 根据原目标、当前产物及结果选择能力和后续步骤。全局目录复核收到本次修改目标，未满足时必须报告阻断。Host 不按评分数量、行业词语或阶段标签生成修复方案。

`bid_project_inspect` 的任务视图提供不可变目标、根范围和检查点步骤。当前 live Main Agent 可对同一可恢复挂起 Work 沿用原授权，替换尚无提交凭据的失败步骤及未开始后缀；已完成步骤、原请求与范围不可修改。计划补丁保存后仍由 `bid_recover_task` 恢复。用户停止、等待输入、不可恢复故障及其他会话不能使用该自动授权。

新的用户目标通过[挂起能力任务接管](2026-09-30-bid-suspended-capability-takeover.md)创建独立 Work；计划补丁只继续本段所述的原目标。

已完成能力恢复原阶段后的纠正入口和重复补丁识别由[已完成能力纠正](2026-10-07-bid-completed-capability-correction-entry.md)补充；本记录的自动恢复授权与未完成步骤限制继续适用。

本决策部分替代[主会话能力工具](../feature/2026-09-24-bid-main-capability-tools.md)和[能力步骤与发布](../architecture/2026-09-24-bid-capability-task-work.md)中仅由后续用户消息替换未开始步骤的限制，并补充[独立恢复授权](../architecture/2026-09-29-bid-goal-decoupling.md)。原 Work 身份、输入校验、项目锁和正式发布约束继续有效。

## Alternatives considered

**按评分关键词固定调用阶段链。** 无法表达不同项目的结构、资料和正文依赖，也会重复已有研究；能力选择由主 Agent 对照真实目标和产物完成。

**只修改提示词。** 失败步骤仍被标记为 running，原授权也不能替换计划；模型知道正确能力仍无法通过受控入口执行。

**让子任务跨范围修改或覆盖已完成步骤。** 破坏任务根范围和已提交结果身份；未完成工作应由拥有原任务的主 Agent 重新规划。

## Consequences

原请求可连续完成，模型仍须负责语义选择及结果验收。自动重规划复用已有检查点和恢复机制，不新增路由规则或持久格式。

单元测试验证原授权、停止限制、错误调用者、已完成结果及后续能力；两节和六节的负例验证仅更新编写要求时，结构目标未达成会阻止完成且保留正式目录。源码 Loader 回放验证一次用户请求内完成失败检查、计划替换、顶层移动和后续改名，并保留正文。真实模型用例覆盖指定章节修改、按实际评分项重组及未达结构目标的复核；其运行需要外部模型凭证和数据传输授权。
