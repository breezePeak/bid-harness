# Agent Note: 流程图 SVG 文字与连线避让

Status: implemented

## Problem

S5 把真实渲染的流程图 PNG 发回同一 Writer，要求文字不溢出、箭头不穿过节点后才能确认。SVG 预览把连线从节点中心画到中心，节点宽度固定为 180 或 190，中文按 18 字换行。14px 字形下这些文字超出边框，箭头穿过节点和文字。Writer 按图片修改流程图，规范化后的 spec 持续变化，4 次尝试内无法完成视觉确认。

## Decision

`nodeSize()` 按 16 字一行、每字 14px 计算文字块。普通节点在文字四周保留 16px 水平内边距和 12px 垂直内边距；判断节点按文字块的两倍加同样内边距放大菱形，使文字落在菱形内部。

`renderFlowchartSvg()` 使用正交折线。正向连线从源节点出边中点出发，在层间空隙折向目标入边中点；回边先沿出边方向离开节点，再走图外侧通道，最后垂直或水平进入目标。箭头停在目标边框外 8px。连线标签放在最长线段旁。回边超出原布局时扩展画布并平移全部内容。图题仍由导出题注绘制，不进入 SVG。

视觉确认提示只要求检查文字溢出、节点重叠、箭头穿过节点或文字、连线标签重叠或压住节点，并说明图题不在图片中。确认条件仍是规范化后的 `metadata.flowcharts` 相同。

## Alternatives considered

**放宽视觉确认，允许 spec 持续变化后直接通过。** 未采用。Writer 仍会看到中心连线和溢出文字，并继续修改本可确认的流程图；S6 也会得到同一张不可读的图。

**把图题画进 SVG。** 未采用。图题已由 Word 题注和 HTML `figcaption` 绘制，画进图片会与导出图号重复。

**让 Writer 直接修改 PNG 或增加独立视觉 Reviewer。** 未采用。既有决策要求 Writer 修改可重渲染的 FlowchartSpec，并由同一会话继承章节上下文。

## Consequences

S5 预览、PNG 视觉确认和 DOCX 内嵌 SVG 使用同一套节点尺寸与正交连线。长中文节点和回边会增大画布，Word 仍按正文宽度缩放。Visio 导出继续使用 `layoutFlowchart()` 的节点边界，连接线仍由 Visio Connector 生成，不使用 SVG 折线。

`flowchart.spec.ts` 固定长中文节点尺寸、回边折点不进入节点、连线标签不落在节点内。
