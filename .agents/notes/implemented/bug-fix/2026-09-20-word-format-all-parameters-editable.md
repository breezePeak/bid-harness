# Agent Note: Word 格式全参数持续编辑

Status: implemented

## Problem

Word 格式页只允许用户处理尚未确认的模板证据差异，正常值和已确认值没有编辑入口，后端还要求保存值必须属于冲突证据候选。模板解析结果因而成为不可纠正的最终设置，用户无法按本次交付要求调整页面、标题、正文、编号、表格、题注或页眉页脚参数。

## Decision

主要格式表的单个值只打开该值对应的字段，行内“修改”只打开该格式角色的字段，表头“修改全部参数”才打开完整参数编辑器。编辑器直接使用 `DocxFormatView.fields`，按字段分组渲染文本、数值、布尔和枚举控件，因此当前部署定义的页面、六级标题、正文、表格、题注、编号及页眉页脚参数无需维护第二份前端清单。局部保存合并既有 `userConfirmed`，不会清除其他已经确认的参数。

编辑器从当前 `resolved` 完整初始化，保存为该模板的 `userConfirmed`。`saveDocxFormat()` 继续执行字段白名单、类型、范围、字体名称、颜色、编号结构、配置 revision 和页面边距校验，但不再要求值来自模板证据候选。用户覆盖参与既有优先级解析并立即更新预览与导出使用的 `resolved`；保存后仍可重复打开和修改。模板证据差异只说明初始值存在多个来源，不限制用户设置。

## Alternatives considered

**继续只编辑未确认差异。** 不采用；确认是一次选择结果，不是锁定格式的授权，正常值和已确认值同样可能需要按交付要求调整。

**为主要表格的每一列维护独立小弹窗。** 不采用；只能覆盖截图中可见字段，页面、三级至六级标题、编号、表格细节和页眉页脚仍不可编辑，还会复制后端字段定义。

**允许编辑任意 JSON。** 不采用；用户只需要受支持的交付参数，内部候选映射、证据和磁盘状态仍由系统管理。

## Consequences

系统默认格式和上传模板都能在任意确认状态下修改全部受支持参数。一次保存会把编辑器展示的完整生效值记录为该模板的用户覆盖，消除已显示的模板内格式差异；切换到其他模板仍读取其独立状态。旧的版本 2 状态和 Remote 请求结构保持不变，不需要磁盘迁移。

[模板证据解析与冲突确认](../feature/2026-09-10-word-template-evidence-resolution.md)继续拥有解析、证据和差异计算；本记录替代其中“用户只能选择证据候选”和“不提供全字段编辑器”的限制。该旧记录仍包含独立的 OOXML 解析与证据优先级 rationale，保留为活动记录，不归档。
