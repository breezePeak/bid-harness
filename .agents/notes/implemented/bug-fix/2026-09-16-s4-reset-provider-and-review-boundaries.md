# Agent Note: S4 产物、重置与联网准入边界

Status: implemented

## Problem

S4 的私有产物版本、前置任务恢复、终审范围和阶段重置需要服从同一份当前输入身份，否则旧复核结论、失效 Work 目录、导出引用或联网错误会在恢复后继续生效。联网工具结果如果只保留错误文本，Host 还无法区分可重试故障与应停止整批任务的 Provider 根因。

## Decision

Web Chunk 索引只依赖严格内容结构与 Source/Snapshot 身份，不生成 `schema_version`；S4 其他正式与恢复产物保留各自的版本协议。旧 S4 运行数据不迁移。前置研究或候选输入失效时，Host 从计划、日志和检查点删除依赖它们的终审与总述任务；前置任务完成后按当前最终目录、依赖和输入 fingerprint 重建范围，发布前确认每个目标可写章节与父节点总述恰有一个有效归属。

Web Runtime 提供不携带密钥的 Provider 诊断，S4 在调度 Child 前按执行时相同的 Provider 选择规则检查 search/fetch，Child 挂载后再次核对工具和 Provider。工具失败保留 Provider 错误码、HTTP 状态与 `retryAfter`；缺失、配置、凭据、认证和额度错误保留首个根因并取消整批任务，限流、搜索超时和临时网络错误使用有限基础设施重试，普通零结果与单页抓取失败仍留给当前任务处理。Tavily 的凭据解析失败使用不含密钥或后端细节的结构化错误。

Final Check 的批量修正使用独立草稿状态，只有完整草稿提交成功后才回写目录、映射和复核状态。每次修正后立即从当前产物刷新待审项和进度。完成校验、结果组装与检查点提交由工具入口和 Host 共享；Child 回合及工具调用全部结束后，Host 仅在当前 generation 的任务、材料和总述都已保留且完整校验通过时幂等收尾，只有工具入口结束模型回合。

阶段重置分别扫描请求文件、请求附属目录和 `runs/<workId>/`，请求元信息与工作树身份同时存在时必须一致，无法确认归属或读取身份的路径使重置失败。项目锁内的同一发布事务清理目标阶段及下游产物、私有工作和实际配置输出目录中的受控导出；自定义输出目录只删除格式状态引用的项目导出。默认格式与每份模板格式只清除失效 `lastExport`，模板字节、解析结果、用户确认和模板选择保持不变。

## Alternatives considered

**保留版本号并增加迁移分支：** 未采用。S4 旧数据已经由重置失效，迁移会扩大恢复路径并让旧结果继续冒充当前阶段输入。

**只在工具注册表中检查联网：** 未采用。工具注册与 Provider 可用性是两个不同边界，凭据解析失败必须在研究任务创建前暴露。

**修正后直接复用原状态：** 未采用。修正可能改变目录和复核指纹，必须以独立草稿原子提交并重新产生待审项。

**让每个章节自行重试 Provider 故障：** 未采用。系统性故障会放大请求并用后续取消或待审错误覆盖首个根因；Host 负责停止调度、取消和等待已启动 Child。

**递归删除配置的输出目录：** 仅默认专用目录采用。自定义目录可能包含用户文件，只能删除项目格式状态持有的失效导出引用。

## Consequences

S4 格式变更需要重置后重新生成，不能从旧检查点续跑；重置会清理对应阶段及下游 Work、检查点、Web 索引和受控导出，但保留原始上传文件、模板和有效上游输入。Provider 诊断只能证明本地配置与凭据可解析，首次真实请求仍负责报告远端认证、额度和网络状态。Host 自动收尾不生成复核结论、不继承旧 fingerprint，也不放宽正式发布校验。
