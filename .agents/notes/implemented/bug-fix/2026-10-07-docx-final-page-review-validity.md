# Agent Note: DOCX 最终页面结论与导出字节绑定

Status: implemented

## Problem

视觉块内容、模板和格式的摘要无法证明最终页面仍相同。前文长度、分页或另一块的缩放都可能改变目标页；按文档顺序只审一次还会使先审块的通过结论对应中间 DOCX。缓存保存页面摘要却未比较它，会把周围排版变化遗漏在验收之外。

## Decision

块的 `inputHash` 保留内容、模板、格式和版本身份；每次导出仍把当前完整 DOCX 转换为 PDF，并为每块定位、栅格化目标页及相邻页。缓存仅在 `inputHash`、当前调整及页面 `outputHash` 一致时跳过模型。页面摘要包含页码、总页数和 PNG 字节，避免相同图片被移动到其他页或全书分页改变时误用结论。DOCX 内部时间戳等字节变化而模型图片输入相同时允许复用。

每次块调整后从第一个视觉块重新检查页面摘要；无法证明未受影响的块重新调用模型。每块在整次导出内累计最多两次调整，回查不会重置预算，因此完整导出最多重渲染两倍于视觉块数量的次数。预算耗尽保存当前失败原因并拒绝导出。缓存版本为 `2`，无法读取的缓存只产生未命中。

每块通过后原子保存缓存；模型中断或后续块失败不丢失已完成结论，重试仍比较当前页面摘要。成功结果同时返回最终 DOCX `outputHash` 与完整 `reviews` 集合；集合内每项的 `documentHash` 都等于最终字节摘要，各项 `outputHash` 则标识实际审核页面。缓存中的当前通过集合在所有块对应同一次最终渲染后再次原子写入，中间通过结论不能代替后续渲染的页面比较。

视觉请求使用当前会话配置的输出预算，缺省时使用模型的 `defaultMaxTokens`，两者都没有时使用 4096；会话日志与真实请求记录同一值。推理模型的预算还包括推理输出，固定 512 可能在 JSON 结论产生前耗尽。非正常结束保留模型终止原因并拒绝本次导出，不把截断结果当成通过。

独立 Word 请求通过 `currentModelSelection()` 读取当前会话选择，未安装选择时使用已记录的请求配置。切换模型立即影响后续视觉复核和格式建议，无需先发一轮对话；模型默认输出预算按当前模型重新解析，显式会话预算继续保留。视觉复核先读取当前模型的图片输入能力，不支持时拒绝发送页面，不另行选择模型。

视觉请求的失败重试使用服务商已解析的 `retryPolicy`，包括错误分类、次数、退避和服务商等待时间；每次实际调用都记录审核输入。等待服从导出取消和单块请求时限，重试耗尽或不可重试失败返回脱敏原因。输出截断和不合法审核结论仍拒绝导出，重试不代替页面验收。

服务商没有返回 HTTP 状态码、但明确说明服务器过载且要求稍后重试时，共享 LLM 分类器仍将其归为 `SERVER`；未知错误不会因为缺少状态码而自动变成可重试错误。分类发生在适配器层，导出消费结构化错误和服务商策略，不维护另一套文本匹配。

此记录部分取代[视觉敏感块缓存](../feature/2026-09-21-docx-visual-sensitive-review-cache.md)中按块输入直接跳过 PDF 与模型的策略；该记录仍拥有敏感块范围、稳定标识、模型参数白名单、真实页面定位和会话输入事件。

## Alternatives considered

**只增加整份 Markdown 或 DOCX 输入摘要。** 未采用；它能保守触发首次审核，但仍需在后块修正后使先块失效，且会因为与目标视觉输入无关的字节变化重复调用模型。

**仅比较块自身图片或几何。** 未采用；它不能覆盖周围正文、模板、字段、相邻页与整书分页共同产生的排版变化。

**每次渲染无条件调用模型审核全部块。** 未采用；实际目标页和相邻页 PNG、页码、总页数以及调整一致时，模型输入已经相同，保留此时的缓存可以减少模型调用。

## Consequences

含视觉块的缓存命中也依赖 PDF 转换和页面栅格化；同一渲染的多个块共享一次 PDF 转换。块调整可能使其他块增加模型请求，这是确保最终交付页面已经验收所需的成本。当前定位范围与视觉模型能力仍受原视觉敏感块记录的限制。

定向测试以确定性渲染和模型替身复现前正文推页、A 推动 B 换页、后块修正影响先块，并验证相同视觉输入复用、模板/样式/几何失效、页码与总页数变化、最终字节绑定、跨块累计预算及中断后复用。LLM 注册入口验证会话预算、模型预算、缺省值、截断诊断、临时服务失败重试、认证失败和重试耗尽。真实 Loader 无密钥场景使用固定 PDF 的实际页面 PNG 验证当前选择覆盖旧请求快照、不支持图片的选择被拒绝、首次 503 后完成审核、模型输入日志、输出预算和缓存复用；真实模型 e2e 使用同一 PDF 页面验证合法审核结论。两者都不证明真实 Word 重渲染效果。
