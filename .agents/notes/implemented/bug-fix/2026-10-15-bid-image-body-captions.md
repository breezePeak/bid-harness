# Agent Note: 正文图题独立于图片资产

Status: implemented

## Problem

图片内容通过视觉确认后，正文审核仍可能要求统一图题。生成请求的标题属于资产语义，修改它会产生新的请求摘要；仅为排版文字重新作图会重复计费，并增加不必要的图片资产。直接修改原资产账本则会使已发布章节的图片记录无法通过一致性校验。

## Decision

Writer 在 `submit_chapter` 的图片位置选择中提交可选 `caption`，程序只用它展开正文替代文字和图题段落。图题为单行非空文本，最多 200 字符；Markdown 标点按普通文本转义。正式 metadata 继续保存账本原图片记录，图片内容、身份、生成语义与项目参考图不随图题修改。

修复投影从实际 Markdown 图片节点的替代文字还原图题，兼容 inline 与 reference 引用；只移除紧随图片且完整匹配的图题段落，其余正文保持原样。同一资产的多处展示须使用同一图题，冲突时拒绝无法无损表达的位置投影。迁入原文通过原文块继续携带原图片及图注。

## Alternatives considered

**重新生成标题不同的图片。** 图题调整不要求改变图像，重新请求产生额外费用与不必要的视觉变化。

**改写资产标题及账本。** 已发布章节仍持有原记录，会失去与账本一致的身份；为图题修改扩大所有引用的更新范围并不必要。

**在正式图片记录中增加图题覆盖字段。** 正文 Markdown 已保存替代文字及图注，新增持久字段会重复同一语义，并要求身份校验区分资产和排版字段。

## Consequences

图题修改不调用生图提供方，前端正文与 Word 继续使用同一图片。真实私有提交工具验证图题限制及身份字段拒绝，回归验证提交、恢复、修复、reference 引用和原文迁入保留原账本、图片与参考图；正式 Loader 图片场景覆盖模型提交图题及正文输出。
