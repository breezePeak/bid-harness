# Agent Note: S4 审核输入范围与补修权限

Status: implemented

## Problem

普通目录审核分片携带全书业务条目及历史意见，历史诊断还混入用户目标，容易将别章或已经关闭的问题归到当前章。补修任务仅允许原来绑定的响应点，又无法完成同评分项遗漏点的修复。不可写父节点的旧职责和覆盖也会让子孙已落实的义务被再次判断为父节点缺项。

## Decision

只有目录补修任务把本范围既有评分项下的全部响应点纳入可选范围。实际章节归属仍由模型按业务选择，程序绑定位置与身份；不会自动把全部响应点写到每章，也不授予其他评分项。提示、业务对象表、依据对象表和正式执行使用同一范围。初始研究、新叶归属和最终检查维持原授权。

不可写父节点的复核索引用 `descendant_coverage_ids` 汇总当前可写子孙覆盖，区别于可写章节的直接归属；不携带尚未重建的旧 purpose 或 must_answer。全局合规归属单独提供，不要求每章重复绑定。完整目录树继续提供父子关系，具体职责依据可写章节核对；父节点正式总述仍由 Final Check 自底向上生成。本规则不改变正式目录的覆盖校验或发布条件。

复核输出只列当前尚未解决的阻断，不返回已关闭或确认通过的事项。Host 在完整报告接纳时拒绝章节、类别和理由均相同的重复问题，沿用格式修复预算；该校验不负责中断仍在生成的输出。

已通过请求按完整提示、角色指令、输出 Schema、Agent 配置和输出预算的指纹记录在研究链执行日志中，后续补修或恢复复用完全相同的成功审核及非阻断建议。章节、采购原文、结构、审核协议或配置变化导致指纹变化，必须重审；阻断和无效报告不产生通过记录。复用时仍以当前正式对象生成覆盖清单并执行确定性校验，未完成请求不能借其他请求的结果放行。

用户修改目标与历史审核意见使用不同输入参数。用户目标只来自已接纳的修改或恢复要求；历史意见单独标明为待核实诊断，其中声称的用户限制不能自行成为新的授权。实际修改直接从当前候选、结构差异和操作记录核对，不重复附加历史操作摘要。审核卡片只携带当前职责与 Blueprint，不附加修改前的 S3 职责，避免已纠正的旧文本再次成为阻断。

普通分片、硬预算分段和意见整理共用章节范围投影：详细片只持有本片章节索引，业务依据、历史意见、差异和操作随索引筛选。全局用户目标只交完整或跨章审核，局部详细片的 Schema 和正式接纳均拒绝 `user_request`；超长目标与待整理意见作为数据完整分段，不放入每片重复的指令。完整跨章关系依据适合模型硬预算时只审核一次，超过硬预算才配对分片；完整精简目录树仍在每片保留。全书确定性覆盖校验在分片前执行，历史意见不能通过公共指令绕过范围筛选。

技术偏离表的审核需求和原文引用复用 `sectionVisibleRequirements()`，与研究和写作共享只读范围；它不因此获得正文覆盖归属。职责索引分别记录覆盖归属与只读上下文引用，关系审核也须保留技术偏离表需求和全局合规条目。审核区分目录层级与业务流转：父子关系证明层级调整，双方职责、输入和输出证明业务交接，不要求并列章节为了交接而嵌套或增加协议未定义的接口字段。

[硬预算分段](2026-10-09-s4-review-partitions-and-legacy-recovery.md)仍拥有原文无损拆分、完整目录树和旧 blocked 恢复；范围筛选同时用于正常请求。[分片终审](../architecture/2026-09-14-s4-sharded-final-review-and-session-authority.md)仍拥有总述生成及终审流程，[目录响应点恢复](2026-09-07-bid-outline-response-point-recovery.md)仍拥有 S3 覆盖修复。以上记录保留各自职责。

## Alternatives considered

**只重试或要求模型补齐编号。** 缺项不在允许范围内时重试无法提交；身份必须由程序绑定，模型不能自行修复引用。

**允许修改全书所有业务归属。** 当前问题只需补齐已承担评分项的响应细点，开放无关评分项会扩大章节职责。

**要求结构父节点复制全部子孙绑定。** 实际作答义务归可写章节，复制会制造两套覆盖状态，并让子节更新后仍需维护冗余父节点。

## Consequences

补修任务会额外看到本范围评分项下尚未分配给本章的响应点，但不会因共享评分而携带其他章节的详细历史。模型仍须判断具体业务归属，阶段质量复核继续阻断真实遗漏和职责冲突。

## Testing

真实工具入口验证同一评分项遗漏响应点的接纳、其他评分项的拒绝以及正式产物保留程序绑定身份。普通分片与硬预算分段都验证别章业务、旧意见和操作不进入当前片；完整目录与跨章关系仍全部覆盖。父节点回归验证子孙覆盖汇总和旧职责排除，输出回归验证重复阻断报告被拒绝后可修正；恢复回归验证用户目标不混入历史意见。真实 Loader 会话快照固定补修范围与目录复核输入。
