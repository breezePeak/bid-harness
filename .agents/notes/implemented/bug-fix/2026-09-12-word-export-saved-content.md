# Agent Note: Word 导出保留完整目录与已保存正文

Status: implemented

## Problem

S5 的目录和正文文件持续存在，但执行记录在重试或修订后可能回到待执行状态。按 completed 筛选 Word 内容会遗漏技术偏离表等已有正文，且丢失其目录节点；审核工作台可见的内容因而无法随文档导出。

## Decision

所有 Word 导出统一按完整确认目录收录已保存正文和父节点概述，不读取执行记录、审核报告、写作计划或章节 Manifest 作为准入条件，也不在导出阶段重新审查正文中的内部编号。缺失或空正文保留目录标题并注明尚无正文，正文与概述均缺失时拒绝导出。目录及正文在读取前后必须稳定，否则拒绝本次导出。文件路径、图片和 DOCX 格式仍须有效；导出不更新审核结论，也不推进 S5。

本记录替代[S5 常驻审核与按需导出](../feature/2026-09-04-bid-s5-persistent-review-export.md)中已完成章节筛选和导出时完整 Manifest 校验。阶段常驻和项目级 Word 互斥仍由原记录及其链接拥有。前端显示 Host 返回的内容范围；正文审核继续由 S5 承担。

[内部身份与客户正文分离](2026-09-11-bid-customer-facing-prose-boundary.md)中的 S3—S5 生成和审核校验继续执行；本记录替代其导出阶段的再次检查，避免审核规则阻止用户取出已有内容。

## Alternatives considered

**继续用完成状态筛选，补充部分导出提示。** 提示无法恢复遗漏的正文，重试仍使导出内容缩减。

**将有正文的章节直接标为完成。** 正文存在不代表审核通过，修改执行记录会干扰修订和阶段恢复。

**仅导出有正文章节的标题。** 缺失章节会从整本目录消失，用户无法辨认尚待补齐的内容；完整目录和明确标注保留这一信息。

## Consequences

定向回归覆盖偏离表审核失败、待执行及执行中正文保留、审核产物缺失或损坏、概述导出、缺失正文标注、空快照拒绝和读取期间目录或正文变化。真实 Loader 回放在执行状态变回待执行后核对导出正文及 Word XML 与完整输出一致；页面回归验证后端范围提示可见。导出可以包含尚待修订的正文，审核结论以 S5 为准。
