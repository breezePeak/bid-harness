# Agent Note: 作图凭据的发送目的地

Status: implemented

## Problem

项目风格文件位于可写工作区。Schema 和摘要能验证字段及内容关系，不能证明接口地址和凭据引用来自用户正式配置。恢复时使用文件中的连接，会允许合法地址或凭据引用被替换后改变密钥的发送目的地。

## Decision

项目风格 v2 只保存语义风格、模型和参考图，拒绝旧格式及额外连接字段。图片提供方的生成入口仅接收语义、图幅、参考字节和模型；每次通过所属正式配置及 pp 设置解析接口、凭据引用和请求限制。项目文件不能指定请求目的地或选择凭据。

提供方解析一次实际连接，在 HTTP 请求前调用程序回调持久化真实请求事件。事件中的模型和地址与随后发送的请求使用同一规范；回调失败或取消时不发送请求。成功图片按语义和模型缓存，配置地址变化不使已有图片重复计费。

## Alternatives considered

**给项目文件的连接加摘要。** 可写文件中的摘要能同时被改写，不能证明用户授权或保护凭据目的地。

**另建冻结连接的签名或历史授权存储。** 项目需要保持风格和模型，不需要独立的网络配置；额外授权存储会引入密钥、生命周期及恢复约定。

## Consequences

已有项目继续保留风格、模型和参考图，接口地址与凭据设置的修改作用于后续请求。回归从提供方生成入口验证文件或额外请求字段不能改变地址和凭据，从真实章节工具验证风格格式拒绝及请求日志持久化。
