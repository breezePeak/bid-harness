# Agent Note: S4 研究事实与当前独立复核

Status: implemented

## Problem

初始 Child 的 `not_required` 和充分性自评可以掩盖零搜索、零阅读的事实。空映射虽有任务复核项，却缺少完整研究自评与真实执行摘要；恢复只检查 completed 或旧 keep，会重复接受同一个未经研究判断的候选。本地资料存在于目录也不能证明当前 Child 读取过正文。

## Decision

研究充分性由模型结合章节任务判断。Host 只从真实工具结果派生执行事实：成功、非空正文才取得已读身份，目录、摘要和搜索分页没有阅读资格。自评仅提供资料需求和理由，不能覆盖次数、状态或失败；缺少历史观察显示未知，明确空观察才表示零执行。本地搜索与 Web 搜索分开计数，调用身份去重。

初始完成表示候选已生成。现有 Final Check 的 task 项同时审查完整自评、当前研究任务、历史候选任务定位、资料目录和真实阅读、失败摘要，以及当前任务、answer_plan 与材料用途；零引用章节也有 task 项。Reviewer 可在原权限内补查，通过已有任务、计划和映射工具修正，再审核当前版本。旧自评作为历史意见保留，不覆盖 Reviewer 已修正的正式结果。

task fingerprint 包含研究语义上下文、当前材料身份和用途、本地正文摘要及既有任务/S2 上下文；本章材料变化使任务、材料及必要祖先总述待审。重复读取和累计次数不参与语义版本，避免复核自身失效。完成、恢复、最终发布及局部能力接纳共用当前复核检查，缺少研究上下文的旧 completed 只重开必要 Final Check，保留初始候选与目录。有效 keep 可恢复，不为计数重复研究。

新材料接纳、实质替换和材料 keep 都要求当前 Child 实际读取；原样保留的正式 baseline 继续接受来源有效性检查。answer_plan 使用的资料须落入最终映射，不能只存在于发现记录；未采用时回执要求采用对应片段或重交计划移除依据，不让模型修复文件身份。Schema 明确检查项选 targets 表、材料选 references 表；计划或材料参数拒绝回执附当前检查项及合法资料位置，供模型选择，过期位置和错误来源仍拒绝。完成检查点等待执行事实落盘，避免进度写入失败后只剩模型自评。

真实项目回放入口挂载现有模型联网适配器，按持久化的搜索策略执行，默认跟随回放 Agent 所选 Provider 与模型；请求使用该 Provider 的连接与凭证，并保留会话中的搜索请求。入口不再自行指定 Tavily。匿名 HTTP 抓取的单个 URL 连接或 TLS 失败返回 `WEB_FETCH_FAILED`，保留真实失败并允许同一 Child 更换来源；不能据此把整个 Provider 判为不可用。Provider 认证、配额和服务错误仍按既有策略中止或有界退避。

本记录部分替代[材料用途复核](../feature/2026-09-08-s4-material-purpose-review.md)中材料变更仅重审单项与旧检查点重置的规则，并明确[研究先于目录深化](2026-09-11-s4-research-before-outline-refinement.md)的 Research Ready 只表示初始自评。两项记录的任务依据、局部权限、结构顺序与无数量门槛仍独立适用，保留并互链。[分段终审和会话权威](../architecture/2026-09-14-s4-sharded-final-review-and-session-authority.md)继续约束分片、闭环和恢复。

## Alternatives considered

**仅加强提示词或按搜索、引用数量放行。** 提示不能证明真实执行，数量也不能决定专业充分性；合理零引用与本地充分章节仍应允许通过独立复核。

**新增研究审批阶段或批准标记。** 现有 task 复核项、版本与 review_records 已能承载判断，新增状态会复制关闭与恢复条件。

**恢复时重跑全部研究，或只按 completed 复用。** 前者浪费有效候选并可能重复结构操作，后者保留旧绕过路径；只补审缺失或过期的当前版本。

## Consequences

材料审核需要当前 Child 读取正文，新增摘要增加有界终审输入；检查点只保存研究摘要，不重复整份 S2 上下文。单元与真实 Loader 无密钥回放证明读取、绑定、失效和恢复链路，不能证明真实模型的专业判断。真实项目回放须具备输入、凭证及向所选模型提供方发送项目内容的授权；未执行时不能宣称语义验收通过。
