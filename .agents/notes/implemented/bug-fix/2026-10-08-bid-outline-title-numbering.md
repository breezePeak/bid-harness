# Agent Note: 输出章节名称与目录编号分离

Status: implemented

## Problem

目录名称包含旧章号时，树位置派生的新号与旧号叠加。只清理侧栏不能修复正文及导出；在历史解析时修改标题又会改变正式摘要，破坏已确认项目及局部编辑范围。

## Decision

`normalizeOutlineSectionTitle()` 只删除开头有明确边界的中文、数字及全角章节前缀，逐层清理叠加编号，保留名称内部字符、业务数字与歧义形式。新模型候选绑定及共用编辑器清理本次显式提交的标题，字段修复只处理授权标题字段；净化后的空名称仍由现有非空校验拒绝。

历史正式目录解析、摘要及确认记录保留原文。UI、目录语义投影、正文根标题及导出组合使用净名称，空结果回退历史原文；来源文档、框架标题路径和资料身份不参与清理。编号来自完整目录树，过滤和折叠不改变编号，左右对比各使用自己的树。Word 使用现有模板原生编号。

正文根标题识别对目录与正文使用同一规则，只合并开头连续明确属于当前章节的标题，其他标题保留且继续受叶节校验约束。浏览器共用 Markdown 源码位置识别，隐藏根标题时保留原文 offset 与 hash，段落审批仍定位原始内容。

本记录补充[目录结构与叶节写作](2026-09-08-bid-outline-structure-before-writing.md)的标题职责及[完整目录导出](2026-09-12-word-export-saved-content.md)的标题组合规则；两者的结构确认、审核与导出时机仍独立适用。

## Alternatives considered

**读取时批量迁移历史标题。** 纯排版修复不应改变已确认摘要、资料映射或正文状态；只读消费兼容加上后续合法编辑即可处理现有项目。

**只隐藏 UI 编号或让模型重新计算编号。** 前者留下正文和导出重复，后者不能确定性适配目录移动，还把程序派生字段交给模型。

**移除所有数字或遍历正文删除标题。** 年份、标准、型号、单位和正文内容会丢失；只识别明确前缀和开头同章标题。

## Consequences

局部编辑保留未触及标题、稳定章节身份和来源引用，CAS 检查仍先验证原始基线，再计算候选 hash。无法明确判断的前缀保留原文，纯编号历史标题回退显示，合法编辑需要提供非空名称。

## Testing

定向回归覆盖模型绑定、候选字段修复、人工编辑、Draft CAS、混合目录、技术偏离表去重、业务数字保护、正文幂等及原文 offset、Markdown 与 DOCX 导出。真实 Loader S3 会话回放提交带旧号候选及质量编辑，固定模型调用次数和净标题落盘。未提供用户项目数据，Word/WPS 实际打开后的分页与目录刷新不由这些自动测试证明。
