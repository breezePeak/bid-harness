# Agent Note: 执行计划只随运行任务显示

Status: implemented

## Problem

通用 Todo 和 Bid 阶段计划在任务结束后仍占据聊天输入区。完成的 S6 步骤重复表达导出结果；已经停止的 Todo 还可能显示“未收尾”，让用户误以为旧操作仍在执行。

## Decision

Todo 计划仅在 Agent 运行、至少有两项且存在未完成项时显示；其持久投影仍按[轮次边界](../feature/2026-07-28-todo-plan-clears-on-next-turn.md)清空。Bid 默认阶段、能力任务和独立 Word 导出的步骤计划仅在各自运行时显示；挂起或失败仍保留阶段状态及错误说明，导出终态由[Word 导出聊天消息](../bug-fix/2026-09-26-bid-word-export-chat-outcome.md)和导出页承载。用户请求需要多步执行时，Agent 仍可在运行回合中列出计划；任务停止后聊天历史和持久事件不被删除。

## Alternatives considered

**清空 Todo 或 Bid 进度事件。** 事件仍是恢复、调试和会话重放的事实，删除会把展示取舍变成数据丢失。

**保留完成计划并默认折叠。** 折叠表头仍占据输入区，且“已完成步骤”不能代替最终结果或错误原因。

**只隐藏全部完成的 Todo。** 失败或中断的旧回合还会留下“未收尾”卡片；以 Agent 运行状态决定展示周期更符合任务执行时间。

## Consequences

输入区只显示正在推进的步骤，历史会话仍保留用户、模型和 Host 已提交的事实。已结束的 Word 导出通过终态聊天消息告知文件位置或失败原因；阶段挂起与失败仍有状态提示供用户判断下一步。浏览器定向测试和真实 Web 回放固定运行态可见、结算后隐藏的行为。
