# Agent Note: 文档维护与站点发布采用中文单语

Status: implemented

## Problem

双语配对记录、合并驱动和对照校验要求每次文档修改同时处理英文正文与一致性元数据。项目当前只要求中文交付，这些检查会把已停止维护的旧配对当成失败，阻碍与现行需求相关的验证。

## Decision

文档维护、检查、流程说明与交付统一使用中文。现有英文 Markdown 正文暂留仓库，但不承担同步义务，也不进入文档站。网站清单只发布中文正文；英文路径仅可作为既有仓库链接的别名指向中文页面。

删除所有 `*.i18n.yaml` 记录、翻译配对清单、校验器、简报、提示词、合并驱动及其测试。归档 Agent Note 的 Markdown 正文继续逐文件封存，配对记录不再属于归档格式。生成目录中的中文链接只在对应目标存在时本地化。

## Alternatives considered

- **保留配对工具但关闭门禁。** 仓库仍会留下可误用的写入命令、合并配置与历史测试，无法清楚表达中文单语规则。
- **同时删除全部英文正文。** 英文正文仍可能被现有仓库链接引用；当前需求明确要求暂留这些文件。

## Consequences

文档修改只需维护中文正文，旧配对测试和记录不再占用验证时间。现有英文正文可能逐渐过时，读者应以中文文档及当前代码为准。中文站点不再提供英文路由；归档正文仍由哈希清单保护。
