# Agent Note: 任务入口、独立资产和原 Word 局部处理

Status: implemented

## Problem

普通聊天、独立作图和已有 Word 配图不需要完整标书的招标分析、目录及写作计划。把这些任务绑定到专业阶段会制造占位文件、扩大写入范围，并使原稿被整书导出替换。附件仅有临时路径也不足以支持队列编辑、恢复及严格的局部授权。

## Decision

沿用[单一任务状态](2026-09-22-bid-single-task-state.md)与[能力 Work](2026-09-24-bid-capability-task-work.md)。新项目的 `workflow` 为空，只有真实用户要求完整标书时由 `bid_start_workflow` 接纳专业路线。能力 Work 没有 stage；阶段执行 Work 保留 stage。插入局部任务先等待旧运行停止，记录其精确 Work 与版本；局部任务结束后按现有产物核定状态，恢复专业路线需要显式继续。

文件接入只保存原件与 Host 生成的身份。提交消息后，完整引用进入持久会话；当前分支只能消费其已有消息引用的附件。解析按内容、原文件名和解析配置共享缓存，专业 Manifest 只绑定角色。重置路线保留原件与独立资产。项目状态 v5、Manifest v5 和 Work 请求 v2 拒绝旧磁盘格式，不静默迁移或删除。

两类独立作图复用现有布局器和 Images API。图片内容审核与最终文档页面审核分开，模型视觉输入均记录会话事件。付费请求先持久登记，再发网络请求；恢复核对已保存结果，无法确定是否成功时禁止自动重发。

原 DOCX 以部件、节点位置及原件摘要绑定目标，在副本中执行白名单补丁。范围外节点与未修改 ZIP 部件保持原样；重复段落不靠文字搜索定位。候选文档独立对象表绑定当前版本，前序步骤的产物通过类型化位置引用解析为完整身份。重规划保留已完成步骤及各自授权，新增要求进入后续核验，不能借旧授权写新范围。

原 Word 配图只有实际 PDF 页面及相邻页通过检查后才形成正式交付；缺少渲染器或视觉能力时保留候选。下载从会话授权和发布凭据取得精确文件，重新校验摘要；模型和浏览器均不能选择任意路径。身份、版本、对象位置表和文件路径只由程序产生。

结果核验从当前 DOCX 的实际 XML 提取正文、题注和页眉页脚文字，并绑定该文件的摘要，避免只有补丁锚点而缺少产物文字证据。文字提取不能替代图像和页面视觉审核，二进制内容不按 UTF-8 解码。正式模型 schema 和持久核验记录禁止独立图、原 Word 要求使用章节新增、写作与迁移标志，避免文件任务进入章节消费者。

页面核验同时取得原稿保留图片与本次可调整图片的身份表，标题、相邻文字和调整位置来自当前 DOCX 节点。原图缺少题注不能被误判为新增图题注分离，也不能成为缩放另一幅新图的理由；新增图片仍须按实际页面核对题注、尺寸和可读性。输出 schema 从正式校验器投影，无效字段和位置只允许在已有修复预算内重新交给视觉模型判断，合法对象范围不扩大，耗尽后禁止发布。

## Alternatives considered

**独立任务伪装成 S1 或 S5。** 会让空招标文件和假目录成为权限依据，并把局部完成误当成专业阶段完成。

**通过整书导出重建用户 Word。** 无法保留原稿的分节、页眉页脚、书签、表格及图片关系；原稿处理使用局部 OOXML 补丁，整书导出继续服务专业路线。

**把作图写成主 Agent 的提示或 Skill。** 缺少确定性产物绑定、付费请求恢复和发布门禁，不能承担可重放的正式能力。

## Consequences

同一主 Agent、Work/Run、输入恢复和发布事务承接普通任务与专业路线。来源授权原文和模型上下文继续分离，问题答案按原问题所有者消费；失败预算属于 Work，终态通知属于 Run，详细恢复约束仍由各自记录维护。

客户端需要的事件与投影声明归属浏览器安全的共享契约，注册实现保留在 Host。客户端不得仅为加载类型声明而引入 Host 插件入口；实际启动 Loader 的测试由 Host 编译配置覆盖。

独立任务查询的空阶段使用 JSON `null`，避免正式工具返回无法无损序列化的值。原稿结构查询、页面审核和计划修改分别说明输入与作用；恢复建议只指导已有步骤执行。核验子会话禁止读取执行者的恢复输入，按冻结的 `task.steps` 判断计划覆盖，防止文字建议被误认成实际保存的能力计划。核验上下文明确区分 `layout_review` 的只读检查与修复模式，修复模式已包含渲染、调整和复验，不能再推定需要额外补丁步骤。

恢复状态公开实际可用的计划修改工具；任务查询刷新 Work 位置表，同时保留已查询的原稿及候选节点身份。后续步骤的解析使用原 Work 请求中冻结的范围，文件任务不能被投影成项目范围。流程图按最长前向路径分层，跨层分支从独立侧面端口绕开中间节点，回边使用独立外侧通道。新题注沿用原稿显示前缀，编号由程序生成，模型提交的编号不作为文档身份。

真实 Loader 回放必须覆盖空会话、附件、独立流程图、原 Word 局部插图、页面渲染、下载拒绝路径及重启复用。原稿夹具包含重复文字、表格、共享图片关系、书签、页眉页脚和分节。独立真实 E2E 只上传夹具并提交自然语言，由真实主模型规划、选位和恢复，真实语义模型及视觉服务核验，保留会话、文档与下载证据；无密钥回放继续承担确定性回归。当前不承诺任意 PDF 编辑、复杂修订修改或 Word/WPS 交互式版面一致。
